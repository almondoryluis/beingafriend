# Frontend

Para realizar la implementación inicial del frontend 
se pueden aplicar estas tecnologías:

* <a href="https://mui.com/toolpad/core/introduction/" target="_blank">Toolpad Core</a>:
    * Toolpad Core es una plantilla de aplicación web basada en 
    <a href="https://es.react.dev/learn" target="_blank">React</a>
    y
    <a href="https://mui.com/material-ui/getting-started/" target="_blank">Material UI</a>.
    * Ofrece una 
    <a href="https://mui.com/toolpad/core/introduction/installation/#automatic-installation" target="_blank">herramienta</a>
    para [generar el proyecto inicial del frontend](./toolpad) en base a dicha plantilla.
* <a href="https://console.firebase.google.com/" target="_blank">Firebase</a>:
    * Firebase es una plataforma de servicios en la nube para desarrollar rápidamente aplicaciones web y móviles.
    * Entre otros servicios, ofrece un servicio llamado 
    <a href="https://firebase.google.com/docs/auth?hl=es-419" target="_blank">Firebase Auth</a>
    para implementar la [gestión de usuarios](./firebase).

Para aplicar estas tecnologías empiece 
[generando el proyecto inicial del frontend](./toolpad/).
