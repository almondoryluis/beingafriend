# Backend

Para realizar la implementación inicial del backend
se puede usar <a href="https://docs.netlify.com/platform/what-is-netlify/" target="_blank">Netlify</a>.

Netlify es una plataforma en la nube mediante la cual:

* Se puede <a href="https://docs.netlify.com/cli/get-started/#manual-deploys">desplegar</a> el frontend.
* Y también, se puede implementar la lógica del backend usando una tecnología llamada _funciones sin servidor_
(<i><a href="https://docs.netlify.com/functions/overview/" target="_blank">serverless functions</a></i>).

El primer paso para utilizar Netlify es [crear una cuenta en Netlify](./crear-una-cuenta-en-netlify/).
