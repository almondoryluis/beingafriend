# Colaboración

Las tecnologías más sencillas que se han encontrado 
para implementar la parte colaborativa del 2do Parcial son:

* <a href="https://console.firebase.google.com" target="_blank">Firebase Realtime Database</a>, una base de datos alojada en la nube, donde los datos se almacenan en formato JSON y se sincronizan en tiempo real con cada cliente conectado.
* <a href="https://www.drawio.com/doc/faq/embed-mode" target="_blank">draw.io en modo embed</a>, un editor de diagramas donde se puede realizar el diseño de las interfaces de usuario.

Comience implementando la parte colaborativa del 2do Parcial
[aplicando Firebase Realtime Database](./realtime-database/) en su proyecto inicial del frontend.
