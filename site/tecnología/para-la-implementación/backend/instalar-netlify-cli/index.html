    Para instalar Netlify CLI

    Instalar

    Para nstalar la herramienta Netlify CLI ejecutar el siguiente comando:

    npm install -g netlify-cli

    Iniciar sesión

    Luego, iniciar sesión en Netlify CLI ejecutando el siguiente comando:

    netlify login

    Al ejecutar el comando anterior, se abrirá en el navegador web la página que se muestra en la siguiente imagen. Hacer clic en el botón "Authorize":

    ¡Felicidades! 🥳🎉 ha instalado Netlify CLI correctamente.
